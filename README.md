# 🎵 Tune Town – Event Booking Website

**Tune Town** is a stylish and responsive event booking website built using HTML, CSS, and Bootstrap. It provides a smooth and engaging way for users to explore and book events such as concerts, gigs, and community festivals.

## 🌟 Features

- 🎫 Clean and modern UI for browsing and booking events  
- 📅 Organized event listings with categories and dates  
- 💡 Bootstrap-powered responsive layout for mobile and desktop  
- 📋 Simple booking form for users to register for events

## 🛠️ Built With

- HTML5  
- CSS3  
- Bootstrap 5
